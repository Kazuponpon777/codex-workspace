# Codex Workspace

Codexでプログラムの作成・修正・動作確認を行うための作業用リポジトリです。

## 現在の状態

初期設定用のリポジトリです。アプリケーションや実行環境はまだ追加していません。

## 作業の始め方

1. Codexでこのリポジトリを選択します。
2. 作成したいもの、または修正したい内容を日本語で伝えます。
3. 変更内容と動作確認の結果を確認します。

既存アプリを修正する場合は、そのアプリのリポジトリを直接選択すると、変更履歴をまとめて管理できます。

## ファイル

- `AGENTS.md`: Codexへの作業指示
- `.gitignore`: Gitに保存しないファイルの設定

## 情報の取り扱い

社内コードを追加する前に、リポジトリが非公開であることを確認してください。
APIキー、パスワード、個人情報、社内の実データはコミットしないでください。
`.gitignore`は補助的な設定です。コミット前に内容を確認してください。
